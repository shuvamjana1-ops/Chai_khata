# UI/UX Pro Max Design Intelligence

## Core Anti-Slop Rules
1. **No Purple Gradients**: Use domain-authentic earthy, editorial, or industrial palettes.
2. **No Default Lucide / Sparkle Icon Clutter**: Use bespoke geometric SVG icons only where functional affordances require them.
3. **No 3-Cards-in-a-Row or Generic Bento Grids**: Use editorial ledger ribbons, asymmetric two-column splits, and ruled tabular lists.
4. **No Glassmorphism Slop or Glowing Background Orbs**: Use crisp paper/ink surfaces with tactile borders and offset shadows.
5. **No Colored Left Accent Stripes**: Use uniform hairline borders (`1px` or `1.5px`) and typographic hierarchy.
6. **No Inter/Geist Defaults**: Pair `Fraunces` (Display Serif) + `Hind` (Humanist Body) + `JetBrains Mono` (Tabular Numerals).
7. **No Emojis in Headings & No Em-Dashes (`—`)**: Keep headings clean and use colons (`:`) or middle dots (`·`) instead of em-dashes.
8. **Custom SVG Favicon & Real Data**: Always provide a custom domain SVG favicon and deterministic domain data.
